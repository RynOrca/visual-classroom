# V2.2 — 出题模式 + 错题本

> 状态：📋 待开发
> 创建：2026-07-13

---

## 一、目标

将当前分散的单题出题能力（`/api/lecture/quiz`）升级为完整的**刷题系统 + 错题本**，覆盖"出题→做题→批改→回顾→薄弱点分析"全链路。

## 二、用户故事

1. 学生在课堂学完一个章节后，点击「开始刷题」→ AI 自动生成一套试卷 → 逐题作答 → 实时批改 → 看到得分和解析
2. 做错的题目自动进入「错题本」→ 随时可以重做 → 连续答对后出狱
3. 定期查看薄弱点分析 → 知识地图上红色越深越需要复习

## 四、数据库变更

```sql
-- 错题本表
CREATE TABLE mistake_book (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  document_id INTEGER REFERENCES documents(id),
  page_number INTEGER NOT NULL,
  quiz_type TEXT NOT NULL DEFAULT 'single_choice',  -- single_choice / multi_choice / fill_blank / short_answer
  question TEXT NOT NULL,
  options TEXT,                                      -- JSON: ["A. xxx", "B. xxx"]
  correct_answer TEXT NOT NULL,
  user_answer TEXT NOT NULL,
  is_correct INTEGER NOT NULL DEFAULT 0,
  knowledge_points TEXT,                             -- 逗号分隔知识点
  created_at TEXT NOT NULL,
  mastered_at TEXT                                   -- NULL=未掌握, 有时间=已出狱
);

-- 刷题记录表
CREATE TABLE quiz_sessions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  document_id INTEGER REFERENCES documents(id),
  total_questions INTEGER NOT NULL,
  correct_count INTEGER NOT NULL,
  score REAL NOT NULL,                                -- 0-100
  details TEXT,                                       -- JSON: 每题结果数组
  created_at TEXT NOT NULL
);
```
