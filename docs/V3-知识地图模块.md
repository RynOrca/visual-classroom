Gemini给的方案：

模块三：游戏地图式全局复习 (Macro Knowledge Map) - 核心重构

解决“学完一堆散装概念，却不知道为什么学、章节之间有何演进逻辑”的痛点。

核心理念：从“物理目录树”升级为“学科演进故事线”。
传统的图谱只展示包含关系，而我们的图谱必须讲透“俯瞰”与“联系”。

功能描述：

上帝视角的演进脉络：AI 不再是简单罗列章节，而是总结章节背后的解决问题导向。例如，俯瞰视角下，地图的连线是这样的逻辑：

[前三章: 如何高效保密 (对称加密)]
⬇️ (为了解决防篡改需求，引出...)

[第四章: 如何防止篡改 (MAC)]
⬇️ (为了追求终极安全，引出...)

[第五章: 理论上的终极合并 (AE)]

无极缩放 (Semantic Zoom)：

Lv1 俯瞰级：只看大章节的串联故事和演进逻辑，一语道破“为什么要学这些”。

Lv2 框架级：滚动鼠标放大，大章节节点展开，露出里面的核心概念框架。

Lv3 痛点级：继续放大，结合右栏的历史提问，用户提问过多次的难点（错题）会变成红色高亮的“热力节点”，点击即可瞬间回到当时对话的“案发现场”。

实现方案：

AI 宏观剧本生成：在渲染地图前，必须有一个独立的 AI Agent 任务读取全书/全课件目录，并使用特殊 Prompt（“请按‘提出问题->解决思路->遗留缺陷->下一章引出’的逻辑，提取本书脉络”）生成 JSON 格式的图谱骨架。

分组嵌套渲染：使用 React Flow 的 Group Nodes（分组节点）或 Sub-flows 能力。外层的 Group 渲染 AI 总结的“演进剧本”，内部嵌套具体的知识节点。
